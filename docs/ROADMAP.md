# Roadmap

- [x] Скан документа на используемые шрифты + проверка доступности в ОС.
- [x] Каталог из 50 популярных Google Fonts (Fontsource CDN).
- [x] Превью каждого начертания через FontFace API.
- [x] Загрузка пользовательского ZIP / отдельных файлов (TTF/OTF/WOFF/WOFF2).

## Этап B — companion (авто-установка)

Цель: после нажатия «Установить и перезапустить Figma» шрифты сразу
оказываются в системе без ручной возни и без админских прав.

### Архитектура

```
[Figma plugin UI] ──HTTP POST──► [127.0.0.1:54827]
                                      │
                                      ▼
                              [companion daemon]
                                      │
                       ┌──────────────┴──────────────┐
                       ▼                             ▼
            ~/Library/Fonts/                 %LOCALAPPDATA%\
                                             Microsoft\Windows\Fonts\
```

### Безопасность companion

- Слушает только `127.0.0.1`, рандомный порт.
- При первом запуске генерирует одноразовый токен → плагин читает его
  через `figma.clientStorage` (после первого запуска юзер копирует токен
  из окна companion).
- HMAC-подпись каждого запроса.
- Лимит на размер файла (1 MB на шрифт), лимит на батч (50 файлов).
- Лог установок: `~/.config/figma-fonts/installs.log` с SHA-256 каждого
  установленного файла + источником (catalog url / user upload).
- Whitelist расширений (`.ttf`, `.otf`).
- Никаких сетевых вызовов наружу — только приём от плагина.

### Стек

- **Go** (один кросс-компилируемый бинарь) или **Rust**.
- Подпись бинаря: Apple Developer ID (macOS notarization) + Microsoft
  SmartScreen-friendly signing (Authenticode).
- Дистрибуция: GitHub Releases, отдельный `.dmg` для mac и `.msi` для win.

### Этапы реализации

1. POC на Go — HTTP-сервер на 127.0.0.1, эндпоинт `/install` принимает
   `{filename, base64bytes}`. Кладёт файл в нужную папку.
2. Регистрация в системе:
   - Windows: `AddFontResourceW` + `WriteProfileString` или просто
     раскладка по `%LOCALAPPDATA%\Microsoft\Windows\Fonts` (с Win10 1809+
     не требует прав).
   - macOS: копия в `~/Library/Fonts/` — система подхватывает автоматически.
3. UI плагина: новая кнопка «Установить» рядом с «Скачать ZIP», доступна
   только если companion отвечает на `/ping`.
4. Подписание бинарей.
5. Auto-update companion через подписанный manifest.

## Этап C — командная работа

- Pull из **корпоративного шрифт-сервера** (организационный CDN с
  лицензированными платными шрифтами — Adobe, Monotype, Linotype) — через
  отдельный коннектор.
- Sync «font kit проекта» между дизайнерами: один человек собирает набор,
  остальные ставят одной кнопкой.
- Отчёт: какие лицензии используются, не нарушены ли условия
  (OFL/Apache vs. proprietary).
