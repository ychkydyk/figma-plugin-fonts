# Шрифты проекта — плагин Figma

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![GitHub](https://img.shields.io/badge/GitHub-ychkydyk%2Ffigma--plugin--fonts-181717?logo=github)](https://github.com/ychkydyk/figma-plugin-fonts)

Сканирует текущий файл Figma, находит используемые шрифты, проверяет, какие
из них уже установлены в системе, и помогает загрузить недостающие из
проверенных open-source источников (Google Fonts, Fontshare) либо из
пользовательского ZIP-архива.

Превью каждого начертания, **авто-выбор только нужных весов** (без лишних,
с возможностью снять чекбоксы), итог — один ZIP с файлами `.ttf`, готовый
к ручной установке. Кросс-платформенный: работает на Windows и macOS
одинаково.

## Установка из git (рекомендуется)

```bash
git clone https://github.com/ychkydyk/figma-plugin-fonts.git
cd figma-plugin-fonts
```

Дальше в Figma Desktop:

1. `Plugins` → `Development` → `Import plugin from manifest…`
2. Выбери `manifest.json` из склонированной папки.
3. Запуск: <kbd>Ctrl/⌘</kbd>+<kbd>/</kbd> → набери «шрифты».

Обновления:

```bash
git pull
```

И сразу запусти плагин — Figma подхватит свежий код с диска.

Подробные инструкции с траблшутингом и установкой шрифтов в систему:

- 🪟 **Windows:** [INSTALL_WIN.md](INSTALL_WIN.md)
- 🍎 **macOS:** [INSTALL_MAC.md](INSTALL_MAC.md)

## Источники шрифтов

| Источник | Что даёт | Лицензия |
|---|---|---|
| **Google Fonts** (через [Fontsource](https://fontsource.org/) на jsdelivr) | ~80 предустановленных популярных семейств в каталоге плагина (Inter, Roboto, Montserrat, JetBrains Mono, Playfair, Bebas Neue и т.д.); полный набор весов и стилей; кириллица для большинства | OFL / Apache 2.0 |
| **Fontshare** (Indian Type Foundry) | ~15 топовых дизайнерских семейств: Satoshi, Cabinet Grotesk, Clash Display, Switzer, Boska, Tanker, Stardom, Erode и др. | Бесплатно для личного и коммерческого использования |
| **Bunny Fonts** (зарезервирован) | Privacy-friendly зеркало Google Fonts без трекеров; запасной CDN при недоступности jsdelivr | OFL / Apache 2.0 |
| **Пользовательский ZIP** | Любые TTF/OTF/WOFF/WOFF2 — фирменные, платные, вырезанные из пресс-китов | по лицензии источника |

Содержимое запросов ограничено `manifest.json.networkAccess.allowedDomains` —
плагин ходит только в эти 7 доменов, не больше.

## Установка плагина

> ⚠️ **Только Figma desktop.** В web-версии Figma локальные плагины разработки недоступны.

1. Открой Figma desktop → создай или открой любой файл (важно: должен быть открыт хотя бы один файл, иначе пункта меню не будет).
2. Меню (☰ слева вверху) → **Plugins → Development → Import plugin from manifest…**
   - Альтернатива: ПКМ на канвасе → **Plugins → Development → Import plugin from manifest…**
3. Выбери файл `manifest.json` из этой папки. Должен появиться тост «Plugin imported».
4. Запуск:
   - Меню → **Plugins → Development → Шрифты проекта — загрузка и предпросмотр**
   - Или quick-search: <kbd>Ctrl/Cmd</kbd> + <kbd>/</kbd>, набери «шрифты»
   - Или ПКМ на канвасе → **Plugins → Development → Шрифты проекта…**

### Если плагин не появился

- **Нет пункта «Development»** — открой любой файл в Figma desktop, без открытого файла этого подменю нет.
- **Импортировал, но не вижу в списке** — открой консоль плагинов: меню → **Plugins → Development → Open console**. Там будут ошибки импорта (например, синтаксис JSON в манифесте).
- **«This plugin requires a newer version of Figma»** — обнови Figma desktop.
- **Импорт прошёл, но запуск падает** — открой консоль плагинов и пришли мне текст ошибки.

## Использование

1. Открой Figma-файл, в котором используются нужные шрифты.
2. Запусти плагин.
3. Вкладка **«Проект»**:
   - Автоматически показывает **только те начертания, что реально используются** в документе (или в выделенных слоях, если переключить на «🎯 Выделение»).
   - Все эти начертания **уже отмечены чекбоксами** — без лишнего: то, что не нужно проекту, не предлагается.
   - Бейджи: «в ОС» (уже установлено) / «нужен» (нет в системе) и «всё установлено» / «не хватает N» на карточке семейства.
   - Снимай чекбоксы с тех начертаний, которые качать не надо.
   - Если в исходнике используется вес, которого нет в каталоге Google Fonts (например, `350`), будет взят ближайший доступный (например, `300`) — это видно в строке.
   - Семейства, которых нет в стартовом каталоге, показываются с пометкой «нет в каталоге» и подсказкой загрузить через ZIP.
4. Переключатель **«📄 Документ» / «🎯 Выделение»** — сужает скан до выбранных слоёв. Если выделение есть при запуске плагина, он сразу переключается на него.
5. Вкладка **«Каталог»** — все 50 популярных Google Fonts, поиск по названию (ручной добор сверх того, что в проекте).
6. Вкладка **«ZIP»** — перетащи свой архив с шрифтами (или россыпью `.ttf` / `.otf` / `.woff` / `.woff2`). Семейства определяются по имени файла.
7. Превью каждого начертания — `@font-face`, текст и размер настраиваются в toolbar.
8. Нажми **«Скачать ZIP»** — браузер сохранит архив с выбранными файлами.

## Установка шрифтов после скачивания

### Windows

1. Распакуй ZIP.
2. Выдели все файлы → ПКМ → **Установить** (для текущего пользователя, без
   админских прав) или **Установить для всех пользователей**.
3. Альтернатива: скопируй вручную в `%LOCALAPPDATA%\Microsoft\Windows\Fonts`.
4. **Перезапусти Figma desktop** — иначе новые шрифты не появятся.

### macOS

1. Распакуй ZIP (двойной клик).
2. Двойной клик по любому `.ttf` → в Книге шрифтов нажми **«Установить шрифт»**.
   Можно выделить все файлы и перетащить в окно Книги шрифтов разом.
3. Альтернатива (быстрее): перетащи все файлы в `~/Library/Fonts/`.
4. **Перезапусти Figma desktop** (Cmd+Q, открой заново).

## Источники шрифтов

- **Google Fonts** через open-source CDN [Fontsource](https://fontsource.org/)
  на jsdelivr — без API-ключа, прямой `.ttf`, OFL/Apache лицензия.
- **Bunny Fonts** — резервное зеркало Google Fonts без трекеров (планируется
  fallback при недоступности jsdelivr).
- **ZIP-аплоад** — пользовательский архив; парсятся `.ttf`, `.otf`, `.woff`,
  `.woff2`. STORE и DEFLATE распаковываются нативно через `DecompressionStream`.

## Безопасность

- Внешние сети ограничены `manifest.json`: только `fonts.googleapis.com`,
  `fonts.gstatic.com`, `fonts.bunny.net`, `cdn.jsdelivr.net`,
  `api.fontsource.org`.
- Нет внешних JS-зависимостей. ZIP-writer (CRC32 + STORE) реализован
  вручную (~80 строк), ZIP-reader использует стандартный
  `DecompressionStream("deflate-raw")`.
- Содержимое пользовательских ZIP не уходит в сеть — обрабатывается локально
  в песочнице плагина.

## Что дальше — этап B (companion)

Плагин Figma из песочницы **не может** установить шрифт в ОС напрямую —
поэтому сейчас ZIP скачивается, и юзер ставит руками. Для авто-установки
запланирован отдельный companion-хелпер (Windows `.exe` + macOS `.pkg`),
который:

- слушает локальный сокет / drag-target,
- получает от плагина массив байт + имя,
- кладёт файл в `%LOCALAPPDATA%\Microsoft\Windows\Fonts` (Windows) или
  `~/Library/Fonts/` (macOS),
- регистрирует шрифт в системе.

Подробнее — в [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Файлы

- `manifest.json` — манифест плагина + allowed domains.
- `code.js` — main thread Figma: сканирует документ, шлёт UI список семейств.
- `ui.html` — UI: три таба, превью, ZIP read/write, скачивание.
- `companion/` — заглушка для этапа B.
- `docs/ARCHITECTURE.md`, `docs/ROADMAP.md` — техдетали и план развития.
